# Исходные данные

- `corridors.geojson` - 15 схематичных морских линий (аналитические ориентиры), без фактического тоннажа.
- `flow_observations.csv` - пустая таблица для подтверждённых объёмов по конкретным маршрутам.
- Сырые AIS, ключи и личные наблюдения храните в `runtime/`: папка исключена из Git.

При добавлении строки в CSV строго сопоставляйте `route_id`, `year`, `cargo_tonnes`, `source_url`, `method`. Для транзитных маршрутов нельзя считать массу по сумме проходов через несколько проливов.
